# FitSpace
Сквозной учебный кейс: от стейкхолдеров и BPMN-схем до UML-диаграмм, C4-архитектуры и SQL-запросов в PostgreSQL. Демонстрация навыков BA. 
# FitSpace: CRM для фитнес-клуба.

Добро пожаловать в мое портфолио по бизнес-анализу!
Этот репозиторий содержит полный набор артефактов, разработанных в рамках сквозного учебного проекта **FitSpace** — системы для автоматизации работы фитнес-клуба.

**Цель проекта:** Уйти от бумажных журналов и ручных записей на ресепшене. Создать личный кабинет для клиентов (покупка абонементов, запись на занятия) и удобную панель для тренеров и администраторов.

## Моя роль
**Бизнес-аналитик.** 
Мои задачи: выявление требований у стейкхолдеров, моделирование бизнес-процессов (AS-IS/TO-BE), написание User Stories, проектирование архитектуры системы (C4) и структуры базы данных (PostgreSQL).

## Инструментарий
*   **Моделирование:** BPMN 2.0, IDEF0, UML (Use Case, Sequence, Class), C4 Model.
*   **Требования:** User Story, Acceptance Criteria (Gherkin), анализ стейкхолдеров.
*   **Данные:** PostgreSQL, SQL (SELECT, JOIN, GROUP BY), ER-моделирование.
*   **Инструменты:** draw.io, DBeaver, GitHub, Markdown.
